# Módulo 8: Páginas de Destino (Landing Pages) de Alta Conversión

## 1. Sitio Web Corporativo vs Landing Page Específica

Un error recurrente en anunciantes principiantes es enviar el tráfico de Google Ads a la página de inicio (Home) de su sitio web general.

| Característica | Sitio Web Tradicional (Home) | Landing Page Dedicada |
| :--- | :--- | :--- |
| **Objetivos** | Múltiples (Informar, blog, acerca de, redes) | **Un solo objetivo (Lead o Venta)** |
| **Menú de Navegación** | Completo con múltiples enlaces de salida | **Sin menú o navegación bloqueada** |
| **Fricción y Puntos de Fuga** | Alta (el usuario se pierde o abandona) | **Mínima (solo hay 1 camino a la conversión)** |
| **Message Match con el Anuncio** | Genérico o difuso | **100% alineado con la keyword y el copy** |
| **Tasa de Conversión Promedio** | 1% - 3% | **5% - 25% (según sector)** |

## 2. La Anatomía de una Landing Page Ganadora para Google Ads

```text
┌────────────────────────────────────────────────────────────────────────┐
│  [Logo]                                   [Teléfono / Botón WhatsApp]  │
├────────────────────────────────────────────────────────────────────────┤
│  HERO SECTION (Above the fold):                                        │
│  • Título H1: Promesa principal que replica la búsqueda del anuncio.   │
│  • Subtítulo: Explicación de la solución + beneficio transformacional.  │
│  • Bullets de Beneficios (3-4 puntos clave).                           │
│  • Formulario / Botón de Acción (CTA) de alto contraste visual.        │
│  • Imagen / Video demostrativo de alta calidad.                       │
├────────────────────────────────────────────────────────────────────────┤
│  PRUEBA SOCIAL Y AUTORIDAD:                                            │
│  • Logos de clientes / Certificaciones / Medios / Años de experiencia. │
│  • Calificación con estrellas y testimonios reales con foto/nombre.   │
├────────────────────────────────────────────────────────────────────────┤
│  CÓMO FUNCIONA / PROCESO EN 3 PASOS:                                  │
│  1. Pide tu presupuesto  ->  2. Coordinamos cita  ->  3. Solución lista│
├────────────────────────────────────────────────────────────────────────┤
│  PREGUNTAS FRECUENTES (FAQ) + GARANTÍAS:                              │
│  • Eliminación de objeciones comunes sobre precio, tiempo y garantía. │
├────────────────────────────────────────────────────────────────────────┤
│  CTA FINAL REPETIDO (Sticky Footer en móviles)                        │
└────────────────────────────────────────────────────────────────────────┘
```

## 3. Principio del *Message Match* (Coincidencia de Mensaje)

El *Message Match* es la correlación visual y de texto entre el anuncio en Google y la página de destino:
1. Si el anuncio dice: *"Instalación de Paneles Solares en Monterrey - Cotiza en 2 Minutos"*.
2. El título principal de la landing page **DEBE** decir: *"Instalación de Paneles Solares en Monterrey - Ahorra hasta 95% en Luz y Cotiza en 2 Minutos"*.
3. Si el usuario llega a una página que dice simplemente *"Bienvenidos a Energía Verde S.A."*, se produce desconexión cognitiva, rebote inmediato y caída drástica del Quality Score.

## 4. Checklist de Optimización Técnica y Persuasión para Landings

- [ ] **Velocidad de Carga**: Carga en menos de 2.5 segundos (móvil y desktop) evaluada en Google PageSpeed Insights.
- [ ] **Mobile-First**: Más del 70% del tráfico en Google Ads suele provenir de móviles; el botón de llamada o WhatsApp debe ser visible sin hacer scroll (o fijo abajo).
- [ ] **Formularios Optimizados**: Solicitar únicamente la información esencial (Nombre, Teléfono/WhatsApp, Email y 1 pregunta cualificadora). Cada campo adicional reduce la tasa de conversión entre un 5% y un 10%.
- [ ] **Página de Gracias Independiente (Thank You Page)**: Para disparar etiquetas de conversión limpias y ofrecer el siguiente paso (ej: *"Un asesor te contactará en breve, o si prefieres escríbenos a WhatsApp ahora"*).
- [ ] **Políticas de Privacidad y Aviso Legal**: Obligatorio en el pie de página para cumplir con las políticas de Google Ads y evitar suspensiones de cuenta.

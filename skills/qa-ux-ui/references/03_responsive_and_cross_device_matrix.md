# Matriz de Pruebas Multidispositivo y Ergonomía Táctil

## 1. Breakpoints de Auditoría Obligatorios
| Dispositivo | Resolución Ancho | Puntos Críticos a Auditar |
| :--- | :--- | :--- |
| **Móvil Compacto** | 360px – 390px (iPhone SE, Galaxy A) | Menú drawer, padding horizontal reducido, tamaño de fuente de títulos. |
| **Móvil Estándar** | 390px – 428px (iPhone 14/15 Pro Max) | Área del pulgar, botón flotante de temario, controles del reproductor. |
| **Tablet Vertical** | 768px – 834px (iPad) | Transición de drawer a sidebar fijo, visibilidad de tabs de recursos. |
| **Desktop Laptop** | 1280px – 1440px (MacBook Air/Pro) | Proporción de aspecto 16:9 del video, ancho del sidebar sin comprimir contenido. |
| **Desktop Panorámico** | 1920px+ (Full HD / 4K) | Max-width en contenedor de video, legibilidad de textos sin estirarse al infinito. |

## 2. Zona Ergonómica del Pulgar (Thumb Zone)
- Los botones de acceso frecuente en móvil (ej. botón para abrir el Temario) deben ubicarse en la zona inferior derecha (Botón Flotante / FAB).
- El drawer debe permitir cierre deslizando hacia la izquierda (Swipe Gesture).

# Hoja de Referencia Rápida: El Semáforo de Decisiones (Felipe Vergara)

Utiliza este resumen para tomar decisiones inmediatas al auditar o revisar campañas de Facebook e Instagram Ads.

---

| Estado | Síntoma / Métrica | Diagnóstico Principal | Acción Inmediata |
| :--- | :--- | :--- | :--- |
| 🔴 **ROJO** | Gasto > 1.5x a 2x el CPA objetivo sin conversiones | Anuncio o conjunto no rentable | **Pausar inmediatamente**. No esperar más gasto. |
| 🔴 **ROJO** | CTR único en el enlace < 0.8% | Creativo aburrido / No detiene el scroll | Reemplazar creativo o cambiar el gancho de los 3s. |
| 🔴 **ROJO** | Pérdida > 25% entre Clics en el enlace y Visitas Web | Fuga técnica / Web extremadamente lenta | Optimizar velocidad web, comprimir imágenes o arreglar enlace. |
| 🔴 **ROJO** | Frecuencia > 3.5 en prospección con CPA subiendo | Fatiga de audiencia (Creative Fatigue) | Cambiar creativos o expandir tamaño de público. |
| 🔴 **ROJO** | Gasto = $0 / Sin impresiones | Anuncio rechazado o puja/audiencia muy baja | Revisar calidad de cuenta, rechazos de políticas y presupuesto. |
| 🟡 **AMARILLO** | CPA en el límite de equilibrio (Breakeven) | Rentabilidad justa / Fricción en conversión | Probar nuevos copies con objeciones o simplificar checkout. |
| 🟡 **AMARILLO** | Alto CTR (> 1.8%) pero baja tasa de conversión en web (< 1.5%) | Desconexión entre anuncio y landing page (*Message Match*) | Ajustar titular de la web para que prometa lo mismo que el anuncio. |
| 🟢 **VERDE** | CPA consistente por debajo del objetivo durante 3-5 días | Rendimiento altamente rentable | **Escalar verticalmente**: Aumentar presupuesto +15% a +20% cada 48h. |
| 🟢 **VERDE** | ROAS superior al objetivo con frecuencia controlada (< 2.0) | Creativo y audiencia ganadora | **Escalar horizontalmente**: Duplicar Post ID a nuevos Lookalikes, Broad o países. |

# Tipografía, Jerarquía Visual y Badges

## 1. Pairings Tipográficos de Vanguardia
- **Headings (Titulares & Eyebrows)**: `Outfit`, `Geist`, `Plus Jakarta Sans`, `Syne` (Pesos 700 / 800).
- **Body & UI Controls**: `Plus Jakarta Sans`, `Inter`, `Geist Sans` (Pesos 400 / 500 / 600).

## 2. Jerarquía de 3 Niveles en Encabezados
Un componente de alto impacto utiliza la estructura **Eyebrow + Title + Meta**:
```html
<div class="header-card">
    <div class="eyebrow-row">
        <span class="badge-tag">MÓDULO 01</span>
        <span class="count-pill">6 lecciones</span>
    </div>
    <h2 class="card-title">Estrategias Avanzadas</h2>
</div>
```

## 3. Píldoras y Badges con Código de Color Semántico
- **Píldora Primaria / Módulo**: `background: linear-gradient(135deg, #6366F1, #A855F7); color: #FFF;`
- **Píldora de Video / Reproducción**: `background: rgba(168, 85, 247, 0.12); border: 1px solid rgba(168, 85, 247, 0.25); color: #C084FC;`
- **Píldora PDF / Documento**: `background: rgba(244, 63, 94, 0.12); border: 1px solid rgba(244, 63, 94, 0.25); color: #FB7185;`
- **Píldora Excel / Hoja de Cálculo**: `background: rgba(16, 185, 129, 0.12); border: 1px solid rgba(16, 185, 129, 0.25); color: #34D399;`
